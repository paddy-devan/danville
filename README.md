# Danville

A tiny pixel art game template built with Phaser 4, TypeScript and Vite. Walk around a green field with the arrow keys.

## Run it on your computer

1. Install [Node.js](https://nodejs.org/) version 22.12 or newer.
2. Open a terminal in this folder and run `npm install` once.
3. Run `npm run dev`.
4. Open the local address printed in the terminal in your browser (usually `http://127.0.0.1:5173`). Use the arrow keys to walk. If the keys do not respond, click the game first.
5. Press `Ctrl+C` in the terminal to stop the game.

To try the production build locally, run `npm run build`, then `npm run preview` and open the address it prints.
