# Starter artwork

These original starter assets were generated with the built-in Image Gen tool for Danville. No asset service or image-generation API is used at runtime. The generated sheet was sliced, trimmed and aligned into 24 × 32 cells, and both assets were reduced with nearest-neighbour sampling. Sharp was used temporarily outside the project for that preparation; it is not a game dependency.

- `characters/farmer-eight-directions.png`: active transparent 72 × 160 PNG, three columns and five rows: down, left, up, down-left and up-left. Right-facing directions mirror the corresponding left-facing row through the JSON `flipX` setting. Eight facing directions use just 15 frames. Each frame's feet sit one pixel above the bottom of its cell. Edit or replace using Piskel or Aseprite.
- `characters/farmer.png`: original four-row starter sheet, retained as a source reference; not loaded by the game. Its down, left and up rows are reused in the active sheet.
- `terrain/grass.png`: repeating 128 × 128 PNG. Edit or replace with a seamless terrain tile.

## Farmer source prompt

Use case: stylized-concept. Production pixel-art character sprite sheet for a very basic top-down farming RPG inspired by classic 16-bit farming games. Transparent background. Exact layout: 3 columns by 4 rows equally sized cells. Rows from top to bottom: character facing down (front), left, right, up (back). Columns: idle standing pose, walking left foot forward, walking right foot forward. SAME brown-haired young farmer, cream shirt, blue dungarees, brown boots in all 12 cells. Slightly elevated top-down view, round tousled brown hair, friendly tiny face, crisp square pixels with dark brown outlines, limited palette. Each character designed on 24x32 logical pixels, then enlarged with nearest-neighbor to fill most of its cell. All 12 character sprites exactly same scale, align feet to identical baseline within each cell, plenty of transparent padding and never crossing cells. Output sheet aspect ratio 3:4. No text, no labels, no grid lines, no props, no scenery, no shadows. Sprite sheet only, actual transparent alpha.

## Diagonal frames source prompt

Generated with built-in Image Gen using the original farmer sheet as the visual reference. The new diagonal rows were trimmed, aligned and reduced with nearest-neighbour sampling, then combined with the three reused cardinal rows. No separate right-facing pixels are stored in the active sheet.

Use case: identity-preserve. Input image is a reference sheet for the EXACT existing farmer character: tousled brown hair, cream shirt, blue dungarees, brown boots, dark brown pixel outlines. Create only the missing diagonal-direction animation frames for this same character and same elevated top-down farming RPG perspective. Production transparent sprite sheet with EXACTLY THREE COLUMNS and TWO ROWS, six equal cells, landscape 3:2 aspect ratio. Top row: facing diagonally DOWN-LEFT (southwest), front three-quarter view, visible face pointing down-left, both eyes with far eye partially obscured, chest and left side visible. Bottom row: facing diagonally UP-LEFT (northwest), rear three-quarter view, back of head and back of blue dungarees visible, small sliver of face/nose on left only. Both rows face LEFT, never right. Columns in each row: standing idle; walking with one foot forward; walking with the other foot forward. Consistent size and foot baseline in all six cells. Flat pixel-art 24x32 logical-pixel character design enlarged with chunky nearest-neighbor pixels, same body/head proportions, same palette and outfit as reference, dark clean outlines. The diagonal views must be distinct from full side profile, full front and full back. Keep sprites isolated with ample fully transparent padding and no contact between cells. No text, no labels, no grid, no shadows, no scenery. Actual transparent alpha background. Do not include the original cardinal direction rows.

## Grass source prompt

Use case: stylized-concept. Production terrain texture for an extremely bare top-down pixel art farming RPG. Square seamless tile of plain spring green grass, base color approximately #72a449, subtle sparse small 1-2 pixel flecks of lighter and darker greens and very occasional tiny three-pixel grass tufts. The entire image is flat even green grass, no objects, no flowers, no stones, no paths, no gradients, no lighting, no borders, no text, no checkerboard. Crisp chunky square pixels, designed as 128x128 logical pixels nearest-neighbor enlarged. Low contrast, very understated texture; continuous green surface from edge to edge and seamless tiling.
